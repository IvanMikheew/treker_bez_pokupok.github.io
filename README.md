# Дни без покупок тканей 🧶

PWA-приложение-счётчик: сколько дней подряд вы не покупаете ткани.

## Возможности

- **Календарь** — в любом прошедшем дне можно отметить, что покупки ткани не было (повторное нажатие снимает отметку).
- **Подбадривающие тексты** — каждый раз, когда вы отмечаете день без покупки, появляется случайное ободряющее сообщение (их больше тридцати).
- **Серия подряд** — крупный счётчик текущей серии дней без покупок; серия не рвётся, если сегодняшний день ещё не отмечен.
- **Статистика** — лучшая серия, всего отмеченных дней, отмечено в текущем месяце.
- **Офлайн и установка** — это настоящий PWA: манифест, иконки, service worker с кэшем. Приложение устанавливается на рабочий стол / в меню и работает без интернета. Данные хранятся в `localStorage` устройства.

## Структура

```
index.html            — разметка приложения
styles.css            — стили (светлая/тёмная тема)
app.js                — логика: календарь, серии, сообщения, хранилище
manifest.webmanifest  — PWA-манифест
sw.js                 — service worker (офлайн-кэш)
icons/                — иконки 192/512 px, включая maskable
```

## Запуск

PWA работает только по HTTP(S) — service worker не регистрируется с `file://`.

```bash
# любой статический сервер, например:
npx serve .
# или
python -m http.server 8321
```

Затем откройте `http://localhost:8321` и (в Chrome/Edge) используйте меню → «Установить приложение».

## Как считаются серии

- **Текущая серия** — количество дней подряд с отметкой «покупки не было», идущих подряд до сегодняшнего дня включительно или до вчерашнего (если сегодня ещё не отметились).
- **Лучшая серия** — самый длинный непрерывный отрезок отмеченных дней за всё время.
